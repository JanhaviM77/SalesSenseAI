# SalesSense AI

A beginner-friendly data analytics and AI portfolio project.

## About the Project

SalesSense AI is a project designed to analyze sales data and turn it into useful business insights.

I am building this project step by step while learning Python, data analytics, SQL, Power BI, and AI.

## Project Goals

- Analyze sales data using Python and Pandas.
- Query and analyze data using Microsoft SQL Server.
- Build interactive dashboards using Power BI.
- Develop an AI agent that helps investigate sales trends.
- Practice Git and GitHub for version control and portfolio building.

## Tools and Technologies

**Currently using:**

**Planned:**

## What the Project Does

- Reads sales data from a CSV file.
- Calculates total sales and profit.
- Groups sales by product.
- Finds the best-selling product.
- Calculates profit margins.
- Creates sales and profit charts.
- Generates a sales summary report.
- Exports the report as a CSV file.

## Project Files

- `sales.csv` - Original sales data.
- `summary_report.py` - Creates the sales summary report.
- `profit_margin.py` - Analyzes profit margins.
- `reports/sales_summary.csv` - Exported sales report.

Other Python lesson files are also included in this repository.

## How to Run the Sales Summary Report

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install Pandas if needed using `pip install pandas`.
4. Run the program using `python summary_report.py`.
5. Open the generated report at `reports/sales_summary.csv`.
