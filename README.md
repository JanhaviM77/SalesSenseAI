
# SalesSense AI

A beginner-friendly data analytics and AI portfolio project.

## About the Project

SalesSense AI aims to analyze sales data and turn it into useful business insights.

We are building this project step by step while learning data analytics and AI.

## Project Goals

- Analyze sales data using Python and Pandas.
- Query and analyze data using SQL Server.
- Build interactive dashboards using Power BI.
- Develop an AI agent that helps investigate sales trends.
- Practice Git and GitHub for version control and portfolio building.

## Technologies

- Python
- Pandas
- Microsoft SQL Server
- Power BI
- Git and GitHub
